# UrbanRoute — Optimización y Análisis de Redes de Transporte Multimodal
UrbanRoute es un proyecto académico desarrollado en Java que busca modelar y analizar redes de transporte urbano multimodal mediante grafos ponderados y una tabla de dispersión (Hash Table) implementados desde cero. La aplicación permitirá visualizar la red de transporte mediante una interfaz gráfica, calcular rutas de menor tiempo con el algoritmo de Dijkstra, identificar subredes desconectadas y estaciones clave, así como gestionar modificaciones y simular interrupciones del servicio.
